## Instagram

Skapa kontot och välj sedan ☰ → Inställningar → **Kontotyp och verktyg
→ Byt till professionellt konto**. Välj **Skapare** eller **Företag** och
kategorin **Appsida** (eller **Sport och friluftsliv**). Instagram kräver
inget registrerat företag.

| Fält | Fyll i |
| --- | --- |
| Namn | `Snöläge · lavinprognos` (syns i sök, så ordet lavinprognos hjälper) |
| Användarnamn | `snolage` |
| Pronomen | Tomt |
| Bio (max 150) | se nedan |
| Länkar | `https://snolage.se`, titel `Snöläge` |
| Kategori | Appsida, visa kategorin på profilen |
| Kontaktalternativ | E-post (se `PROFILER.md`), inget telefonnummer |

```
Lavinprognos, väder, karta och turplanering för svenska fjällen 🏔️
Gratis. Ingen reklam. Byggd av en toppturåkare.
⬇️ snolage.se
```

**Kontocenter:** Fabian valde (11 okt 2026) att inte lägga in sina privata
Instagram- och Facebook-konton i samma Meta-konto som `snolage`. Tryck på
krysset när Meta frågar igen. Schemalägg i stället direkt i Instagram-appen
(Avancerade inställningar → Schemalägg när du lägger upp), och lägg upp på
Facebook-sidan separat.

**Höjdpunkter:** när du har lagt upp stories, skapa en höjdpunkt per ämne och välj bilden med samma namn som omslag: `hojdpunkt-sa-funkar-det.png` (Så funkar det), `hojdpunkt-lavinproblem.png` (Lavinproblem), `hojdpunkt-snolaget.png` (Snöläget), `hojdpunkt-fran-faltet.png` (Från fältet).
