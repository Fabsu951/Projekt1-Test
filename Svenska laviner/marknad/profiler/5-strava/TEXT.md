## Strava-klubb

Strava → **Utforska → Klubbar → Skapa en klubb** (enklast i webbläsaren
på strava.com).

| Fält | Fyll i |
| --- | --- |
| Namn | `Snöläge` |
| Typ | Klubb / Annat |
| Sport | Vintersport eller Multisport (om topptur finns som eget val, ta det) |
| Plats | Sverige |
| Webbplats | `https://snolage.se` |
| Profilbild | `profilbild.png` |
| Omslag | `omslag.png` |
| Öppen eller sluten | Öppen |

Beskrivning:

```
För oss som åker topptur och offpist i de svenska fjällen. Här delar vi Snöläget inför helgen, tips om lavinprognoser och turplanering, och nyheter om appen Snöläge. Alla är välkomna att gå med och dela sina turer.

Appen är gratis: snolage.se
```

**Bilder i den här mappen:** `profilbild.png`, `omslag.png`
