## YouTube (för Shorts)

Skapa kanalen från ditt Google-konto: profilbilden → **Skapa en kanal**.
Välj att använda ett eget namn.

| Fält | Fyll i |
| --- | --- |
| Namn | `Snöläge` |
| Handtag | `@snolage` |
| Profilbild | `profilbild.png` |
| Bannerbild | `banner.png` (texten ligger i mitten, där den syns på alla skärmar) |
| Länkar | `Snöläge` → `https://snolage.se`, plus Instagram och TikTok |
| Kontakt-e-post | se `PROFILER.md` |

Beskrivning:

```
Snöläge är en gratis app för dig som åker topptur och offpist i de svenska fjällen. Här lägger vi upp korta klipp om lavinprognoser, lavinproblem, varningstecken och turplanering, och om hur appen fungerar.

I appen: Naturvårdsverkets lavinprognoser, SMHI:s väder och varningar, snödjup, Lantmäteriets karta med lutning, karta offline, ruttplanering som jämförs med dagens lavinproblem, observationer och turdagbok.

Gratis, utan reklam. Ersätter inte egen bedömning eller lavinkurs.

snolage.se
```
